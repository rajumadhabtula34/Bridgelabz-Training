# **Bank Account Management**

## **Objective**

Develop a Java application to manage a bank account and implement a debit operation that prevents withdrawing more money than the available account balance.

## **Features**

* Create an account with an initial balance.
* Deposit money using the `credit()` method.
* Withdraw money using the `debit()` method.
* Validate that the debit amount does not exceed the available balance.
* Display the updated account balance after every transaction.

## **Technologies Used**

* Java
* Eclipse IDE
* Object-Oriented Programming (OOP)
* Scanner

## **Classes**

* **Account**
* **AccountTest**

## **Output**

Displays the account balance before and after the debit operation. If the debit amount exceeds the available balance, an appropriate message is displayed.
