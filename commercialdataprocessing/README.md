# **Commercial Data Processing**

## **Objective**

Develop a Java application to manage company shares using Object-Oriented Programming concepts.

## **Features**

* Create a stock account.
* Buy company shares.
* Sell company shares.
* Calculate the total value of all company shares.
* Store the date and time of every transaction.
* Display a detailed stock report.
* Save stock details to a file.

## **Technologies Used**

* Java
* Eclipse IDE
* Object-Oriented Programming (OOP)
* ArrayList
* File Handling

## **Classes**

* **CompanyShares**
* **StockAccount**
* **CommercialDataProcessing**

## **Output**

Displays company share details, transaction time, stock values, total account value, and saves the report to a file.
