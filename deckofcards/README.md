# **Deck of Cards**

## **Objective**

Develop a Java program to initialize a deck of 52 playing cards, shuffle them randomly, distribute 9 cards each to 4 players, and display the cards received by every player.

## **Features**

* Create a standard deck of 52 cards.
* Shuffle the deck using the `Random` class.
* Distribute 9 cards to each of 4 players.
* Store cards in a two-dimensional array.
* Display the cards received by each player.

## **Technologies Used**

* Java
* Eclipse IDE
* Arrays
* Random Class
* Object-Oriented Programming

## **Classes**

* **DeckOfCards**

## **Output**

Displays 9 randomly shuffled cards for each of the 4 players.
