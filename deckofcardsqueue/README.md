# **Deck of Cards Using Queue**

## **Objective**

Develop a Java application to distribute a deck of cards among four players using a Queue implemented with a Linked List.

## **Features**

* Create a standard deck of 52 cards.
* Shuffle the deck randomly.
* Distribute 9 cards to each of 4 players.
* Represent each player as an object.
* Store each player's cards in a Queue implemented using a Linked List.
* Display the cards received by every player.

## **Technologies Used**

* Java
* Eclipse IDE
* Object-Oriented Programming (OOP)
* Linked List
* Queue
* Random

## **Classes**

* **Card**
* **Node**
* **Queue**
* **Player**
* **DeckOfCardsQueue**

## **Output**

Displays the cards received by each player after shuffling and distributing the deck.
