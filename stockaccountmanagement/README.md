# **Stock Account Management**

## **Objective**

Develop a Java application to manage stock details and generate a stock report by calculating the value of each stock and the total value of all stocks in the portfolio.

## **Features**

* Read stock details from the user.
* Store multiple stocks using `ArrayList`.
* Calculate the value of each stock.
* Calculate the total value of all stocks.
* Display a complete stock report.
* Implemented using Object-Oriented Programming concepts.

## **Technologies Used**

* Java
* Eclipse IDE
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner

## **Classes**

* **Stock**
* **StockPortfolio**
* **StockAccountManagement**

## **Output**

Displays the stock name, number of shares, share price, value of each stock, and the total value of all stocks in the portfolio.
